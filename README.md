## ۱. تحلیل و حل مرحله اول: تاتی تاتی (`tati-tati`)

### صورت مسئله
پاسخ در توضیحات مرحله مستقیماً داده شده است:
> «پاسخ این یکی را از همان اول به تو گفتیم: `YEK{YektaNet}` — دقیقا همین، حرف به حرف. تمام سؤال، پیدا کردن جایی بود که باید ثبتش کنی.»

### منطق تحلیلی
در رابط کاربری سایت هیچ دکمه‌ای برای ارسال پاسخ (Submit) وجود ندارد. با بررسی کدهای فرانت‌اند (`static/js/ctf.js`) مشخص می‌شود که طراحان چالش توابعی را روی آبجکت گلوبال `window.ctf` و محیط کنسول اکسپورت کرده‌اند.

### نحوه حل
با باز کردن کنسول مرورگر (DevTools -> Console) یا ارسال مستقیم درخواست به API:
```javascript
// انتخاب چالش
select("tati-tati");

// ارسال پرچم
submit("YEK{YektaNet}");
```

یا از طریق ترمینال با `curl`:
```bash
curl -X POST https://256.yektanet.tech/ramzolmasal/api/submit \
  -H "Content-Type: application/json" \
  -b "ctf_device=<COOKIE>; ctf_session=<COOKIE>" \
  -d '{"flag": "YEK{YektaNet}"}'
```

**نتیجه:** باز شدن جعبه ابزار کنسول مسابقه و باز شدن چالش‌های بعدی.

## ۲. تحلیل و حل مرحله دوم: کلاغ (`kalagh`)

### صورت مسئله
> «یه کلاغه یه خبری آورده، ولی می‌دونی که حرف تو دهن کلاغ‌جماعت بچرخه، دیگه اون حرف اولی نمی‌مونه. دنبال قصه رو بگیر، ببین آخرش چی به گوشت می‌رسه.»

### منطق تحلیلی
۱. فایلی به نام `api/files/qanun.txt` در دسترس قرار می‌گیرد که قوانین کلاغ‌ها را شرح می‌دهد:
   - شروع: `GET api/kalagh`
   - الگوریتم اثبات کار (Proof-of-Work): الگوریتم هش **FNV-1a** (32-bit unsigned):
     ```python
     h = 2166136261
     for b in data.encode('ascii'):
         h = ((h ^ b) * 16777619) & 0xFFFFFFFF
     ```
   - شرط خوش‌صدایی: `h < 2048` برای رشته‌ی `payam:nonce`.
   - ارسال پاسخ به `POST api/kalagh` با فرمت `{"shomare": n, "nonce": "..."}`.
۲. بر اساس ضرب‌المثل **«یک کلاغ چهل کلاغ»**، پیام باید دقیقاً تا کلاغ شماره ۴۰ دست‌به‌دست شود. اگر پس از مرحله ۴۰ ادامه دهید، سرور خطای زیر را برمی‌گرداند:
   > `بسه دیگه، قار قار! قصه یه جایی همین پشتا تموم شده بود.`
۳. پیام اختصاصی بازگردانده شده از کلاغ شماره ۴۰، متن داخل پرچم نهایی است: `YEK{<PAYAM_40>}`.

### اسکریپت حل پایتون
اسکریپت کامل در فایل `scripts/solve_kalagh.py` قرار دارد.

## ۳. تحلیل و حل مرحله سوم: نگهبان دربار (`negahban`)

### صورت مسئله
> «نگهبان دربار، سند تو را نمی‌پذیرد مگر آنکه دو متن کاملا متفاوت بیاوری که نگهبان حواس‌پرت، مهر هر دو را یکی ببیند. نگهبان دربار به لطف یک خطای قدیمی در سنجیدن، گول ظاهر این شاهدان ساختگی را می‌خورد. دو سند فریبنده بساز، مهر تایید را بگیر و کلید آزادی را پیدا کن.»

### سرنخ موجود در Charm
> `«وقتی نگهبان یه فیل پیر باشه هر گردی رو گردو میبینه»`

### منطق تحلیلی و آسیب‌پذیری
- **فیل پیر (Old Elephant):** نماد زبان PHP.
- **هر گردی رو گردو میبینه + خطای قدیمی در سنجیدن:** به آسیب‌پذیری معروف **PHP Type Juggling / Loose Comparison (`==`)** در مقایسه رشته‌های هش اشاره دارد.
- در PHP نسخه ۵ تا ۷، اگر دو رشته با `0e` شروع شده و مابقی کاراکترها ارقام باشند، مفسر PHP آنها را نماد نمایی (Scientific Notation) عدد صفر (`0 × 10^x = 0`) تلقی کرده و عبارت `"0e123" == "0e456"` را `true` ارزیابی می‌کند.
- به این رشته‌ها **PHP Magic Hashes** می‌گویند. نمونه‌های مشهور برای MD5:
  - سند اول: `240610708` -> هش MD5: `0e462097431906509019562988736854`
  - سند دوم: `QNKCDZO` -> هش MD5: `0e830400451993494058024219903391`

### نحوه ارسال و دریافت پرچم
با ارسال درخواست POST به `api/negahban`:
```bash
curl -X POST https://256.yektanet.tech/ramzolmasal/api/negahban \
  -H "Content-Type: application/json" \
  -b "ctf_device=<COOKIE>; ctf_session=<COOKIE>" \
  -d '{"sanad1": "240610708", "sanad2": "QNKCDZO"}'
```
پاسخ سرور:
```json
{"kilid": "abe4edb8aa926a67", "mohr": true}
```
سپس ثبت کلید با انتخاب مرحله `negahban`:
```bash
submit("YEK{abe4edb8aa926a67}")
```

### اسکریپت حل پایتون
اسکریپت کامل در فایل `scripts/solve_negahban.py` قرار دارد.
